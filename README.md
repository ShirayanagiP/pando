# 판도

브라우저에서 행정구역을 색칠하고 범례와 라벨을 편집하는 개인 지도 작업실입니다.

- 거시판도학: 세계 1차 행정구역, 유럽 중심 / 아시아 중심
- 대륙판도학: 동아시아
- 미시판도학: 대한민국 읍면동, 선거구 획정, 권역과 의석 배정

## 사용

정적 사이트의 시작 파일은 index.html입니다. 별도의 서버 프로그램, 패키지 설치나 빌드 과정은 필요하지 않습니다. GitHub Pages를 사용할 경우 이 저장소의 루트를 게시 소스로 지정할 수 있습니다. .nojekyll을 포함했습니다. 이 저장소에 파일을 준비하는 작업만으로 사이트가 게시되지는 않습니다.

작업은 현재 브라우저에 자동 저장됩니다. PC와 휴대폰 간 자동 동기화 기능은 없으므로 작업 저장 / 불러오기의 JSON 파일로 옮기세요. 추가 글꼴도 현재 브라우저에만 보관됩니다. 브라우저 데이터 삭제에 대비해 중요한 작업은 JSON으로 보관하세요.

## 공개본 범위

게임 추출 데이터, 개인 작업 JSON과 이미지, 로컬 서버, 원본 자료 전체와 개발용 도구는 포함하지 않았습니다. 게임 지도는 개인용 지도 팩을 현재 브라우저에 가져와 사용할 수 있습니다. [개인용 지도 팩 안내](PRIVATE_MAPS.md)를 참고하세요. 가져온 팩은 서버로 전송하지 않으며 공개 저장소에도 포함하지 않습니다.

[외부 자료와 라이선스](THIRD_PARTY_NOTICES.md), [지도 자료 안내](data/README.md), [OpenStreetMap 파생 데이터 다운로드](data/odbl/README.md)를 확인하세요. 자료별 조건이 다르므로 프로젝트 전체에 단일 라이선스를 부여하지 않았습니다.

PUBLICATION-MANIFEST.json에는 선별된 공개 파일의 크기와 SHA-256을 기록했습니다. .gitignore는 명시된 공개 파일만 새로 추가하도록 제한하므로 새 기능 파일을 추가할 때 해당 목록도 갱신하세요.
