# 대한민국 미시판도학 자료와 가공 내역

- 지도 단위: **읍 235개 · 면 1,168개 · 행정동 2,150개 = 3,553개**, 상위 시군구 252개.
- 행정구역 기준: **2024-04-01** 버전. 최신 행정구역으로 해석하지 않습니다. 출장소는 독립된 읍면동으로 추가하지 않습니다.
- 선거구 기준: **2024-04-10 제22대 국회의원선거 지역구 254개**.

## 행정동 경계

통계청 SGIS · 행정안전부 변경 이력 → 김승범 / VW Lab의 [vuski/admdongkor](https://github.com/vuski/admdongkor), `ver20240401/HangJeongDong_ver20240401.geojson`.
원본은 `external/korea-micro/administrative-dongs-20240401.geojson`, 고정한 커밋은 `upstream.json`, 해시는 `provenance.json`에 보관합니다.
원자료는 공공누리 제1유형(출처표시), 추가 가공물은 CC BY 4.0입니다. 함께 보관한 `LICENSE-ADM-DATA.txt`를 참고하세요.
자료 제공자가 같은 버전에 반영한 사후 경계 보정도 원본 그대로 포함됩니다.

읍·면은 그대로, 동은 행정동으로 처리합니다. 법정동·리·통·반을 별도 편집 단위로 추가하지 않습니다.
공유 경계를 단순화하고 0.01 지도 단위의 정밀도 격자에서 노딩하여, 인접한 양쪽이 동일한 경계선을 사용하게 했습니다.
화면은 축척별 3단계 상세도와 화면 밖 지역 생략을 사용하고, SVG·PNG 출력은 전체 편집 경계를 사용합니다.
한국어와 원어는 원본 지명, 영어는 빌드 시 `korean-romanizer 0.28.0`으로 생성한 음독 표기입니다.

## 선거구 소속

소속은 **공직선거법 [별표 1], 2024-03-08 개정, 국회의원지역선거구구역표**의 읍면동 목록과 시군구 일원 조항에서 추출했습니다.
원문 PDF: `external/korea-micro/official-law-appendix.pdf`.
공개 법령 별표의 [법제처 검색 원문](https://www.law.go.kr/lbook/lbFileDownload.do?flExt=pdf&lbookConflSeq=110881&lbookSeq=109281), [서울시 공개 첨부파일 사본](https://dataseoul.s3.ap-northeast-2.amazonaws.com/upload/S2023082267ff5819580d3/466ca56d38746.pdf).
법제처 다운로드 서버 오류로 실제 번들에는 같은 별표의 공개 첨부파일 사본을 보관했습니다.

표 추출: `scripts/extract-korea-election-table.py` (빌드 시 pdfplumber 필요).
표의 254개 선거구 이름과 원문 구역: `official-districts.json`.
`prepare-korea-micro.py`는 모든 읍면동을 이 목록과 대조하며, 누락 또는 중복 소속이 있으면 빌드에 실패합니다.
`membership-validation.json`의 누락·미해석 항목은 모두 0개입니다.

선거구 코드 및 보조 경계 대조: [오마이뉴스 / 2024_22_elec_map](https://github.com/OhmyNews/2024_22_elec_map), MIT, `LICENSE-ELECTION.txt` 포함.
통계청 행정동 기반으로 제작된 경계이며, 서로 다른 경계 자료의 면적 교집합은 검증용으로만 사용했습니다.
당하동은 면적 다수결로 서구 을에 잘못 들어갈 수 있으므로, 구역표에 따라 **인천 서구 병**으로 연결됩니다.
공식 목록 순서를 유지하며, 은평구 갑의 9개 행정동을 포함한 모든 3,553개 읍면동이 정확히 하나의 선거구에 소속됩니다.

위 구역표는 편집을 시작할 때의 초기값입니다. 사용자는 선거구 이름·읍면동 소속을 수정하거나 선거구를 추가·삭제할 수 있습니다. 수정 구성은 원자료와 별개로 프로젝트 JSON의 `elections`에 저장합니다. 읍면동 중복 배정은 허용하지 않으며 미배정 상태는 허용합니다.

선거구·권역 단계는 색칠·라벨 없이 경계를 편집합니다. 권역은 기본값 없이 사용자가 추가하며 생략할 수 있습니다. 의석 단계는 정당 1·정당 2·정당 3·무소속을 초기 정당으로 두고, 사용자가 정당 이름·색상을 수정하고 지역구당 1석을 배정합니다. 권역별 비례대표제 설정은 임시 버튼만 있으며 비례 의석 계산은 구현하지 않았습니다. 일반 범례의 색칠과 선거구 구성·권역·정당 배정은 별도로 유지합니다. PNG·SVG는 현재 단계의 지도와 정당별 의석 수를 출력합니다.
